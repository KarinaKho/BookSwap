# BookSwap

Веб-приложение для обмена учебной и художественной литературой между студентами.

## Возможности
- регистрация пользователей с указанием вуза и факультета;
- публикация книг, доступных для обмена;
- поиск книг по названию, автору, дисциплине и курсу;
- заявки на обмен и выбор места встречи;
- рейтинг и отзывы пользователей.

## Структура репозитория
| Ветвь | Содержимое |
|---|---|
| `main` | описание проекта, требования, анализ конкурентов |
| `database` | SQL-схема базы данных и ER-диаграмма |
| `frontend` | прототип главной страницы (HTML/CSS) |

## Стек технологий
PostgreSQL, Python (Flask), HTML/CSS/JavaScript.

Учебный проект. Управление задачами ведётся в Kaiten по методологии Kanban.
