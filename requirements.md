# Требования к веб-приложению BookSwap

## 1. Функциональные требования
| ID | Требование | Приоритет |
|---|---|---|
| F-01 | Регистрация и вход по e-mail | Высокий |
| F-02 | Заполнение профиля: вуз, факультет, курс | Высокий |
| F-03 | Добавление книги: название, автор, дисциплина, состояние, фото | Высокий |
| F-04 | Поиск и фильтрация каталога по дисциплине, курсу, состоянию | Высокий |
| F-05 | Отправка, принятие и отклонение заявки на обмен | Высокий |
| F-06 | Выбор места встречи для обмена | Средний |
| F-07 | Отзывы и рейтинг после завершения обмена | Средний |
| F-08 | Уведомления о новых книгах по выбранным дисциплинам | Низкий |
| F-09 | Модерация объявлений администратором | Средний |

## 2. Нефункциональные требования
- время загрузки страницы каталога — не более 2 с;
- адаптивная вёрстка для экранов от 360 px;
- хранение паролей только в виде хеша;
- поддержка браузеров Chrome, Firefox, Safari, Edge последних двух версий.

## 3. Пользовательские истории
1. Как студент первого курса, я хочу найти учебник по дисциплине, чтобы не покупать его.
2. Как студент старшего курса, я хочу выставить ненужные учебники, чтобы освободить место и помочь другим.
3. Как участник обмена, я хочу видеть рейтинг собеседника, чтобы доверять ему.
